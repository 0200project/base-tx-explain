What it decodes

Swaps on Uniswap V2, V3, and V4 and Aerodrome; ERC-20, ERC-721, and ERC-1155 token transfers; NFT mints, transfers, and Seaport sales; OP-stack bridge deposits and withdrawals; Aave V3 and Compound V3 lending; staking, wrapping, and claims; ERC-4337 account-abstraction bundles; EAS attestations; Basename registrations; and contract deployments — 30 action types from roughly 40 builtin event formats, with app-specific events named via verified ABIs on Sourcify. When a transaction can’t be fully decoded, the output says so instead of guessing. Full enum in the response schema, common questions in the FAQ.
