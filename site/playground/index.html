The Explain button is live: it sends your hash to the production MCP endpoint from your browser, and each live call counts against your own free tier (50 calls per IP address per day, shared behind one address, then $0.02 per call via x402).

outputexplain_transaction

Click a sample chip to replay stored output instantly, or paste a hash and hit Explain to decode it live against the production endpoint.

The full response schema — all 30 action types and 8 risk flags — is in the docs. If your free tier runs out here, the response is the same x402 payment challenge an agent pays through; this page renders it so you can see what agents see.

risk_flags lists only flags backed by evidence — it is never a safety verdict, and no flags does not mean clean. The checks field alongside it says which underlying lookups actually ran (ok, partial, unavailable, inconclusive, or not_applicable), with a plain-language note whenever one didn’t — so an empty flag list can be read correctly instead of mistaken for clearance. A stored sample’s checks reflect the moment it was captured; decoding the same hash live right now can show different values if an upstream source is temporarily degraded — that is the tool working honestly, not a bug.
